# 🛡️ Fraud Detection System

## 📌 Overview

This project demonstrates a simple **Fraud Detection System** built using Python. It analyzes transaction data and classifies transactions as **Fraud** or **Normal** based on predefined rules. The project also includes visualizations to better understand fraudulent activity.

This project was completed as part of the **CodeAlpha Data Analytics Internship**.

---

## 🚀 Features

- Analyze transaction data
- Detect fraudulent transactions using rule-based logic
- Classify transactions as **Fraud** or **Normal**
- Visualize fraud distribution using charts
- Display only suspicious transactions
- Simple and beginner-friendly implementation
